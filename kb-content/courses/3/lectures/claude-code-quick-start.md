# Claude Code: быстрый старт

Claude Code — это инструмент командной строки от Anthropic, который позволяет взаимодействовать с Claude прямо в терминале. Он помогает писать код, искать ошибки и автоматизировать рутинные задачи.

## Установка

Для установки Claude Code выполните команду:

```bash
npm install -g @anthropic-ai/claude-code
```

После установки запустите `claude` и авторизуйтесь через браузер.

## Первый запуск

Первый запуск Claude Code требует выбора рабочей директории и подтверждения доступа к файлам. Система покажет краткое руководство и предложит начать с простых команд.

## Основные команды

- `claude` — начать интерактивную сессию.
- `/help` — показать список доступных команд.
- Ctrl+C — прервать текущий запрос.
- `exit` — завершить сессию.

## Безопасность

Claude Code запрашивает разрешение перед любыми изменениями файлов и выполнением внешних команд. Всегда проверяйте предлагаемые правки перед их применением.
