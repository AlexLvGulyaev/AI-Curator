# CC01. Установка и первый запуск Claude Code

## Что такое Claude Code

Claude Code — это официальный инструмент командной строки от Anthropic. Он позволяет взаимодействовать с моделью Claude прямо в терминале, редактировать файлы, запускать команды и автоматизировать рутинные задачи разработки.

## Системные требования

- Node.js 18 или новее.
- macOS, Linux или Windows с WSL.
- Доступ к интернету для авторизации.

## Установка

Установите Claude Code глобально через npm:

```bash
npm install -g @anthropic-ai/claude-code
```

Проверьте установку:

```bash
claude --version
```

## Первый запуск

1. Откройте терминал в рабочей директории проекта.
2. Введите команду:

```bash
claude
```

3. Система предложит авторизоваться через браузер. Следуйте инструкциям на экране.
4. Выберите рабочую директорию и подтвердите доступ к файлам.

## Безопасность

Claude Code запрашивает разрешение перед любыми изменениями файлов и выполнением внешних команд. Всегда проверяйте предлагаемые правки перед их применением.

## Практическая проверка

После успешного запуска попробуйте команду:

```bash
claude
```

Затем задайте простой вопрос, например: «Какие файлы есть в текущей директории?»
