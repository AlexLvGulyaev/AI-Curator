# CC02. Интерфейс и основные команды Claude Code

## Интерфейс Claude Code

Claude Code работает в терминале и использует текстовый интерфейс. Основные области:

- Поле ввода запроса внизу экрана.
- История диалога сверху.
- Предложенные действия и правки в средней части.

## Основные команды

| Команда | Действие |
|---------|----------|
| `claude` | Запустить интерактивную сессию. |
| `/help` | Показать список доступных команд. |
| `/exit` или `exit` | Завершить сессию. |
| Ctrl+C | Прервать текущий запрос. |

## Режимы работы

Claude Code умеет:

- отвечать на вопросы по коду;
- редактировать файлы по запросу;
- запускать shell-команды с разрешения пользователя;
- искать по проекту и анализировать структуру.

## Пример диалога

```
User: Найди все функции, которые отвечают за обработку ошибок.
Claude: В проекте найдено 5 таких функций: ...
```

## Горячие клавиши

- `Tab` — автодополнение команд.
- `↑` / `↓` — навигация по истории запросов.
- `Enter` — отправить запрос.
- `Ctrl+D` — завершить сессию.

## Безопасность

Claude Code никогда не выполняет опасные команды без явного подтверждения. Перед правкой файла показывает diff и просит подтвердить изменения.
