# CC10. Интеграция Claude Code в рабочий процесс

## Где использовать Claude Code

Claude Code можно встраивать в разные этапы разработки:

- исследование кода перед задачей;
- парное программирование;
- отладка;
- написание коммит-сообщений;
- подготовка PR-описаний.

## Интеграция с git

Claude Code умеет работать с git-репозиторием. Можно просить:

- показать diff;
- объяснить изменения;
- предложить коммит-сообщение;
- найти авторов изменений.

## Пример запроса

> Покажи последние изменения в файле src/main.py и объясни, зачем они были сделаны.

## Workflow: начало задачи

1. Опишите задачу Claude Code.
2. Попросите найти релевантные файлы.
3. Обсудите план реализации.
4. Применяйте изменения пошагово с проверкой.

## Workflow: завершение задачи

1. Попросите написать тесты.
2. Попросите обновить документацию.
3. Попросите сформировать описание PR.

## Ограничения

Claude Code не заменяет CI/CD, code review и тестирование. Он ускоряет рутину, но финальная ответственность остаётся за разработчиком.
