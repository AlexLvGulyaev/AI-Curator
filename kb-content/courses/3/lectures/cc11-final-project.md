# CC11. Итоговый проект: автоматизация с Claude Code

## Цель проекта

Применить полученные навыки работы с Claude Code для автоматизации реальной задачи в собственном проекте.

## Идеи проектов

1. Автоматическая генерация моделей и CRUD для новых сущностей.
2. Скрипт для массового рефакторинга legacy-кода.
3. Инструмент для анализа и классификации ошибок в логах.
4. Генератор документации по коду.

## Этапы выполнения

1. **Анализ**: выберите задачу, которую можно автоматизировать.
2. **Планирование**: сформулируйте требования и ограничения.
3. **Разработка**: используйте Claude Code для создания решения.
4. **Тестирование**: проверьте результат вручную и автоматически.
5. **Документирование**: зафиксируйте, как использовать полученный инструмент.

## Критерии оценки

- Решение решает реальную задачу.
- Код понятен и поддерживаем.
- Есть тесты или примеры использования.
- Описана инструкция по запуску.

## Пример итогового проекта

Создать CLI-утилиту, которая по описанию сущности генерирует SQLAlchemy-модель, Pydantic-схемы и FastAPI-endpoints, а затем добавляет их в проект.

## Защита проекта

Подготовьте короткое описание:

- какую задачу решали;
- как использовали Claude Code;
- какие сложности возникли;
- какой результат получился.
