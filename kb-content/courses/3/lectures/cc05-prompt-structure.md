# CC05. Структура эффективного промпта

## Что такое промпт

Промпт — это текстовый запрос к языковой модели. Качество ответа напрямую зависит от того, насколько чётко сформулирован запрос.

## Компоненты хорошего промпта

1. **Роль** — кто отвечает на вопрос (например, опытный разработчик).
2. **Контекст** — что нужно знать для ответа.
3. **Задача** — что именно нужно сделать.
4. **Формат** — в каком виде должен быть ответ.
5. **Ограничения** — что нельзя делать или нужно избегать.

## Пример плохого промпта

> «Напиши код.»

Модель не понимает язык, назначение и требования.

## Пример хорошего промпта

> Ты Python-разработчик. Напиши функцию `validate_email`, которая проверяет строку по RFC 5322 и возвращает `True` или `False`. Используй только стандартную библиотеку. Добавь docstring и примеры.

## Шаблон

```
Роль: ...
Контекст: ...
Задача: ...
Формат ответа: ...
Ограничения: ...
```

## Практика

Перепишите запрос «объясни recursion» по шаблону выше. Сравните ответы до и после.
