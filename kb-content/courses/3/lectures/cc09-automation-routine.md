# CC09. Claude Code и автоматизация рутины

## Автоматизация с Claude Code

Claude Code помогает автоматизировать повторяющиеся задачи разработки:

- генерация boilerplate-кода;
- массовый рефакторинг;
- написание тестов;
- обновление документации;
- анализ логов.

## Примеры рутинных задач

- Переименовать функцию во всём проекте.
- Добавить типизацию ко всем функциям модуля.
- Сгенерировать CRUD для новой сущности.
- Написать README для нового сервиса.

## Как автоматизировать

1. Опишите задачу конкретно.
2. Укажите файлы и ограничения.
3. Попросите Claude Code предложить план действий.
4. Проверяйте каждое изменение перед применением.

## Пример запроса

> В проекте на FastAPI нужно добавить endpoint для управления домашними заданиями. Сущность `Homework` связана с `Course` и `Student`. Используй SQLAlchemy и Pydantic. Напиши миграцию, модель, схемы и CRUD-endpoints.

## Предупреждение

Автоматизация не отменяет code review. Всегда проверяйте сгенерированный код перед коммитом.
