# CC03. Первый диалог с Claude Code

## Как начать диалог

Запустите Claude Code в директории проекта:

```bash
claude
```

После запуска вы увидите приглашение для ввода запроса. Введите свой вопрос и нажмите Enter.

## Примеры первых запросов

- «Объясни, что делает этот проект.»
- «Найди главный файл приложения.»
- «Покажи структуру проекта.»
- «Как запустить тесты?»

## Контекст

Claude Code автоматически видит файлы в рабочей директории. Это позволяет задавать вопросы напрямую по коду без копирования текста в чат.

## Уточнение запросов

Если ответ слишком общий, добавьте детали:

- вместо «исправь баг» — «исправь функцию handle_error в файле utils.py»;
- вместо «добавь тест» — «добавь unit-тест для функции calculate_total».

## Сохранение истории

История диалога сохраняется в рамках одной сессии. После выхода история не сохраняется локально, поэтому важные результаты лучше фиксировать в файлах или внешних заметках.

## Практическое задание

Запустите Claude Code и задайте три вопроса о вашем проекте. Зафиксируйте самые полезные ответы.
