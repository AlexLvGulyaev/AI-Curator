# ДЗ: Установка и первый запуск Claude Code

## Задание

1. Установите Claude Code глобально через npm:

```bash
npm install -g @anthropic-ai/claude-code
```

2. Проверьте версию:

```bash
claude --version
```

3. Запустите Claude Code в любой рабочей директории:

```bash
claude
```

4. Авторизуйтесь через браузер.

5. Задайте минимум три вопроса о файлах в директории.

## Результат

Скриншот терминала с запущенным Claude Code и примером диалога.
