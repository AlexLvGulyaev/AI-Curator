# ДЗ: Claude Code и автоматизация рутины

## Задание

1. Выберите рутинную задачу в своём проекте:
   - массовое переименование;
   - генерация boilerplate;
   - написание однотипных тестов;
   - обновление документации.

2. Сформулируйте задачу для Claude Code максимально конкретно.

3. Попросите Claude Code:
   - предложить план автоматизации;
   - написать скрипт или инструкцию;
   - выполнить изменения пошагово.

4. Проверьте результат вручную.

## Результат

Описание задачи, план автоматизации и итоговый скрипт/инструкция с вашими правками.
