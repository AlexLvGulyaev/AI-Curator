# ДЗ: Интеграция Claude Code в рабочий процесс

## Задание

1. Опишите свой реальный рабочий процесс при выполнении одной учебной или рабочей задачи.

2. Отметьте этапы, где Claude Code может помочь:
   - исследование кода;
   - написание;
   - отладка;
   - документирование;
   - подготовка PR.

3. Попробуйте использовать Claude Code хотя бы на двух этапах реальной задачи.

4. Зафиксируйте, что получилось, а что — нет.

## Результат

Короткий отчёт с примерами запросов к Claude Code и оценкой пользы на каждом этапе.
