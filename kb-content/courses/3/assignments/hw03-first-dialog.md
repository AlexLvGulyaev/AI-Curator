# ДЗ: Первый диалог с Claude Code

## Задание

1. Запустите Claude Code в директории учебного проекта.

2. Задайте три вопроса:
   - «Объясни, что делает этот проект.»
   - «Какие зависимости используются?»
   - «Как запустить приложение?»

3. Сохраните наиболее полезный ответ.

## Результат

Три вопроса и ответы Claude Code. Отметьте, какой ответ был самым полезным и почему.
