# ДЗ: Ролевые промпты и контекст

## Задание

1. Выберите одну и ту же задачу.

2. Сформулируйте запрос в трёх ролях:
   - преподаватель для начинающих;
   - senior-разработчик;
   - технический писатель.

3. Добавьте контекст: описание проекта, стек технологий, ограничения.

4. Сравните ответы Claude Code.

## Результат

Три промпта, три ответа и вывод о том, как роль и контекст повлияли на результат.
