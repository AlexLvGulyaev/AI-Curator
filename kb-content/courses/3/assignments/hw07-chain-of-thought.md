# ДЗ: Chain-of-thought и разбор сложных задач

## Задание

1. Выберите сложную задачу из своего проекта или придумайте архитектурный вопрос.

2. Сначала попросите Claude Code решить её в один шаг.

3. Затем попросите решить ту же задачу с chain-of-thought: «Расскажи, как ты пришёл к ответу, шаг за шагом.»

4. Сравните оба ответа.

## Результат

Два ответа и вывод: в каких местах chain-of-thought улучшил качество.
