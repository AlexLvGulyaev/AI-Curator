# ДЗ: Структура эффективного промпта

## Задание

1. Выберите любую задачу по программированию.

2. Сформулируйте её в виде плохого промпта (общего и непонятного).

3. Перепишите промпт по шаблону:
   - Роль
   - Контекст
   - Задача
   - Формат ответа
   - Ограничения

4. Отправьте оба промпта Claude Code и сравните результаты.

## Результат

Два промпта, два ответа и краткий вывод о том, как структура повлияла на качество.
