# ДЗ: Итоговый проект

## Задание

1. Выберите реальную задачу автоматизации в своём проекте.

2. Используя Claude Code, разработайте решение:
   - сформулируйте требования;
   - получите план реализации;
   - напишите код;
   - добавьте тесты или примеры использования;
   - подготовьте документацию.

3. Проверьте решение вручную.

## Результат

- описание задачи;
- итоговый код;
- тесты или примеры;
- инструкция по запуску;
- краткий отчёт о том, как Claude Code помог на каждом этапе.
