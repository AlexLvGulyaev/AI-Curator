# ДЗ: Интерфейс и основные команды

## Задание

1. Запустите Claude Code.

2. Выполните команды:
   - `/help`
   - запрос «Покажи структуру проекта»
   - запрос «Найди главный файл приложения»

3. Попробуйте прервать выполнение запроса с помощью Ctrl+C.

4. Завершите сессию командой `/exit`.

## Результат

Текстовый отчёт с описанием:
- что показала команда `/help`;
- какие файлы Claude Code счёл главными;
- как работает прерывание запроса.
