# Модуль 3. Ролевые и контекстные промпты

## Ролевые промпты

Когда модели задаётся роль, ответ становится более специфичным и согласованным.

```
Ты — senior-разработчик Python с опытом ревью кода.
Проверь функцию ниже и укажи потенциальные баги и улучшения.
```

## Контекстные промпты

Контекст помогает модели понять рамки задачи. Важно давать ровно столько контекста, сколько нужно.

### Слишком мало контекста

```
Объясни рекурсию.
```

### Слишком много контекста

Длинный пересказ всего проекта без фокуса на вопросе.

### Оптимально

```
Объясни рекурсию на примере вычисления факториала. Аудитория — студенты первого курса.
```

## Комбинация роли + контекст

```
Ты — преподаватель информатики для новичков. Объясни, что такое API, на примере заказа еды через приложение.
```
