# Модуль 2. Структура эффективного промпта

## Фреймворк RICE

Эффективный промпт можно собрать по шаблону RICE:

- **R**ole — роль, которую выполняет модель.
- **I**nstruction — чёткая инструкция.
- **C**ontext — необходимый контекст.
- **E**xpectation — ожидания от результата.

## Пример

```
Ты — опытный UX-писатель.
Инструкция: перепиши заголовок лендинга, чтобы он был короче и убедительнее.
Контекст: продукт — онлайн-курс по промпт-инжинирингу.
Ожидание: три варианта по 5–7 слов каждый.
```

## Проверка качества

Хороший промпт отвечает на вопросы:

- Понятна ли задача?
- Хватает ли контекста?
- Формат вывода задан явно?
- Есть ли ограничения?

## Практика

Берите плохой промпт и последовательно добавляйте недостающие компоненты. Сравнивайте ответы до и после.
