# Модуль 4. Chain-of-thought и структурирование

## Chain-of-thought (CoT)

CoT — это техника, при которой модель просят рассуждать пошагово. Это повышает точность на сложных задачах.

```
Реши задачу, объясняя каждый шаг:
В магазине 5 яблок стоят 120 рублей. Сколько стоят 8 яблок?
```

## Zero-shot CoT

Можно добавить волшебную фразу:

```
Давай разберём пошагово.
```

## Структурирование сложных запросов

Разбивайте сложную задачу на части:

1. Сначала проанализируй.
2. Затем выдели ключевые пункты.
3. Наконец, сформулируй рекомендации.
