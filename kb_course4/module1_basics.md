# Модуль 1. Основы промпт-инжиниринга

## Что такое промпт

Промпт — это текстовый запрос, который подаётся языковой модели для получения осмысленного ответа. Качество промпта напрямую влияет на полезность, точность и безопасность ответа.

## Базовые компоненты

1. **Инструкция**. Что нужно сделать: "Объясни", "Перепиши", "Сгенерируй".
2. **Контекст**. Фоновая информация, необходимая для ответа.
3. **Входные данные**. Текст, код, таблица — то, над чем выполняется задача.
4. **Формат вывода**. JSON, Markdown, список, таблица.

## Пример простого промпта

```
Перепиши следующий текст более деловым языком:
Текст: "Привет! Нам нужно поговорить про сроки, потому что всё затянулось."
```

## Чего избегать

- Двусмысленных формулировок.
- Избыточного контекста, который запутывает модель.
- Запросов, требующих доступа к приватным данным.
