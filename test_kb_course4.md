# Промпт-инжиниринг в контексте n8n

## Введение

В этом курсе мы изучаем, как писать эффективные промпты для языковых моделей, которые вызываются из n8n workflow.

## Ключевые принципы

1. **Явная роль**: сообщите модели, кто она. Например: "Ты — senior-разработчик n8n".
2. **Контекст входных данных**: опишите, какие поля приходят из предыдущего узла n8n.
3. **Формат выходных данных**: JSON, Markdown, plain text — укажите явно.
4. **Обработка ошибок**: попросите модель вернуть структурированный ответ даже при недостатке данных.

## Пример промпта для n8n

```
Ты — аналитик данных. Тебе передаётся объект JSON с полями name, email, status.
Классифицируй status как "active", "inactive" или "pending".
Верни только JSON без пояснений.
```

## Отличие от общего промпт-инжиниринга

В n8n промпт обычно короче, структурированнее и ориентирован на машиночитаемый вывод, потому что результат часто передаётся в следующий узел автоматизации.
