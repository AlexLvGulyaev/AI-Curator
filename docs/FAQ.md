# ❓ AI Curator — частые вопросы

**Проект:** ai-curator  
**Дата:** 2026-08-05

---

## 💡 Общие вопросы

### 🤖 Чем AI Curator отличается от обычного чат-бота?

AI Curator работает с двумя независимыми источниками: LMS (учебный процесс) и База знаний (учебные материалы). Он даёт персонализированные ответы с явными ссылками на источники и чёткими границами: не выставляет оценки, не меняет дедлайны.

### 👨‍🏫 AI Curator заменяет преподавателя?

Нет. AI Curator берёт на себя рутинные вопросы, чтобы преподаватель мог сосредоточиться на сложных случаях и развитии курса.

### 🛠️ Какие данные нужны для запуска?

- Moodle LMS с включёнными Web Services и read-only токеном.
- База знаний с учебными материалами.
- API-ключ OpenAI для LLM и embeddings.

## 🎓 Для студента

### ✅ Можно ли доверять ответу?

Каждый содержательный ответ содержит ссылку на источник — задание в LMS или материал в Базе знаний. Если источник не найден, AI Curator явно сообщит об этом.

### 🔗 Как увидеть источник ответа?

В Веб-интерфейс под ответом AI отображаются карточки источников. LMS-источники — кликабельные ссылки на задания. База знаний-источники — информационные бейджи с названием документа и его типом (`lecture`, `methodical`, `faq` и др.).

### 🚫 Почему AI Curator не отвечает на вопрос про оценку?

AI Curator не имеет права выставлять или изменять оценки. Это остаётся в компетенции преподавателя и LMS.

### 🎭 Что такое demo-роли?

Это преднастроенные профили студентов для публичной демонстрации: `active_student` (активный студент), `late_student` (отстающий студент), `new_student` (новый студент).

## 👨‍🏫 Для преподавателя

### 🔄 Нужно ли что-то менять в LMS?

Нет. AI Curator читает существующую структуру курсов, задания и дедлайны из LMS. Главное — чтобы данные были актуальными.

### 📊 Как AI Curator узнаёт прогресс студента?

Через LMS API в рамках разрешённых read-only прав.

### 📈 Можно ли получить аналитику по вопросам студентов?

Да. Консоль администратора содержит Панель аналитики и Управленческие отчёты с популярными темами, вопросами без ответа и гэпами База знаний.

## 🎛️ Для администратора AI Curator

### 🔑 Какие права нужны для интеграции с Moodle?

Read-only токен Moodle Web Services с правами на чтение курсов, пользователей, заданий, прогресса и групп.

### 🗄️ Где хранятся логи?

Операционные логи хранятся в PostgreSQL. Hot logs архивируются через 30 дней, LLM traces — через 7 дней. Архивы — gzip JSON Lines в `ARCHIVE_DIR`.

### 📤 Как экспортировать логи?

В Консоль администратора: Операционные логи → **Экспорт CSV**, Журнал аудита → **Экспорт CSV**, Диалоговые сессии → **Экспорт CSV**.

### 🔒 Что такое safe demo mode?

Ограниченный режим публичного Веб-интерфейс с квотой `20` запросов на сессию, rate limit и таймером `30` минут. Защищает API-лимиты при публичных демонстрациях.

## 🧠 Для методиста

### 📥 Как быстро добавить новый материал?

1. Консоль администратора → База знаний → Загрузить файл.
2. Заполнить метаданные: название, тип (`lecture`, `methodical`, `faq`, `instruction`...), `course_id`, `module_id`, `topic_id`, язык, описание.
3. Выбрать файл (Markdown, TXT, PDF).
4. Сохранить.
5. Выбрать документ в списке и нажать **Переиндексировать**.

### 🔍 Почему новый материал не появляется в ответах?

Возможные причины:

- документ не переиндексирован;
- метаданные не совпадают с LMS-контекстом студента;
- embedding model недоступна.

### 📝 Как обновить устаревший материал?

Загрузите новую версию документа. Она автоматически становится активной. После переиндексации старая версия заменяется в векторном индексе.
