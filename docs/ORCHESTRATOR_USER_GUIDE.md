## 🎯 1. Назначение

Orchestrator определяет, как AI Curator обрабатывает вопросы студентов:

1. **Классифицирует запрос по интенту** — `deadline`, `progress`, `study`, `mixed`, `organizational`.
2. **Выбирает источники данных** — Moodle LMS и/или Knowledge Base AI Curator.
3. **Задаёт лимиты контекста и token-бюджеты** для управления latency и качеством ответов.
4. **Настраивает fallback-сообщения** и фильтры курсов.

---

## 🚪 2. Как открыть

1. Откройте [▶️ Консоль администратора](https://curator-admin.alex-n8n.site).
2. Войдите с Bearer-токеном (`ADMIN_CONSOLE_TOKEN`).
3. В Sidebar выберите раздел **Оркестратор**.

## 🧩 3. Секции консоли

### 🏷️ 3.1. Intent Classification

Карточки для каждого интента:

- **Keywords** — фразы, по которым Orchestrator понимает, что вопрос относится к этому интенту. Одна фраза на строку.
- **Priority** — приоритет правила. Меньше число = выше приоритет. Применяется только к интентам, определённым через conditions. `deadline` и `progress` определяются по keywords раньше и не участвуют в сравнении priority.
- **Дополнительно** — дополнительные условия: чекбоксы, требующие наличия организационных (`is_org`), учебных (`is_study`) или progress (`is_progress`) keywords. Если выбрано несколько чекбоксов, backend строит составное условие `{and: [...]}`.
- **Default intent** — интент по умолчанию, если ни одно правило не подошло.

### 🔀 3.2. Source Routing

Таблица **Маршрутизация источников** по интентам:

| Intent | LMS | RAG | strict_course | Назначение |
|--------|-----|-----|---------------|------------|
| `deadline` | ✅ | ❌ | ✅ | Только данные LMS |
| `progress` | ✅ | ❌ | ✅ | Только данные LMS |
| `organizational` | ✅ | ❌ | ✅ | Только данные LMS |
| `study` | ❌ | ✅ | ❌ | Только Knowledge Base |
| `mixed` | ✅ | ✅ | ✅ | LMS + Knowledge Base |

- **LMS** — обращаться к Moodle за курсами, дедлайнами, прогрессом.
- **RAG** — искать фрагменты в Базе знаний.
- **Strict** — жёстко фильтровать RAG по `course_id` текущего курса. Если выключено, разрешены общие материалы из других курсов.

### 📐 3.3. Limits & Token Budgets

| Параметер | По умолчанию | Описание |
|-----------|--------------|----------|
| **Max contents** | 12 | Сколько элементов курса передавать в prompt LLM. |
| **Max deadlines** | 5 | Сколько ближайших дедлайнов передавать в prompt LLM. |
| **Organizational** | 500 tokens | Максимальная длина ответа LLM на организационные вопросы. |
| **Study beginner** | 650 tokens | Максимальная длина ответа на учебные вопросы в режиме beginner. |
| **Mixed** | 800 tokens | Максимальная длина ответа на смешанные вопросы (LMS + KB). |
| **Default** | 750 tokens | Максимальная длина ответа на остальные сценарии, включая advanced-study. |

Бюджеты — это soft-лимиты: модель постарается не превысить их, но не гарантирует заполнение до предела. Если ответы часто обрезаются, бюджет можно увеличить, но latency вырастет.

### 💬 3.4. Fallbacks & Course Starters

- **No LMS data** — ответ, когда в LMS нет запрошенных данных.
- **No RAG context** — ответ, когда в Базе знаний ничего не найдено.
- **Out of scope** — шаблон отказа, когда студент спрашивает про недоступный курс. Используйте `{course}` для подстановки названия.
- **Non-course starters** — слова, с которых начинаются обычные вопросы, но которые не являются названием курса. Помогают избежать ложного срабатывания «курс не найден».

## 💾 4. Как сохранить

1. Внесите изменения в нужные секции.
2. Нажмите **Сохранить** в правом верхнем углу.
3. Backend сохранит конфигурацию и автоматически сбросит кэш чата, чтобы изменения применились к новым запросам.

> **Примечание:** в демо-режиме (`ADMIN_CONSOLE_DEMO_TOKEN`) кнопка **Сохранить** отключена; backend вернёт `403` на любое изменяющее действие.

---

## 💡 5. Подсказки

- Наведите курсор на название параметра — появится всплывающая подсказка (tooltip).
- Не меняйте `intent_source_map` без понимания последствий: LMS — Source of Truth для организационных вопросов, Knowledge Base — для учебных.
- Для добавления нового типа вопроса используйте `keywords` в существующем intent или создайте новый intent + source map.
