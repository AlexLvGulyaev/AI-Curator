# Orchestrator — руководство пользователя

## Назначение

Orchestrator определяет, как AI Curator обрабатывает вопросы студентов:

1. Классифицирует запрос по интенту (deadline, progress, study, mixed, organizational).
2. Выбирает источники данных (LMS, База знаний).
3. Задаёт лимиты и fallback-сообщения.

## Как открыть

Консоль администратора → **Orchestrator**.

## Секции

### 1. Intent Classification

Карточки для каждого интента:

- **Keywords** — фразы, по которым Orchestrator понимает, что вопрос относится к этому интенту. Одна фраза на строку.
- **Priority** — приоритет правила. Меньше число = выше приоритет. Используется, если запрос подходит сразу к нескольким интентам.
- **Advanced** — дополнительные условия: можно потребовать наличие организационных, учебных или progress keywords.
- **Default intent** — интент по умолчанию, если ни одно правило не подошло.

### 2. Source Routing

Таблица источников по интентам:

- **LMS** — обращаться к Moodle за курсами, дедлайнами, прогрессом.
- **RAG** — искать фрагменты в Базе знаний.
- **Strict** — жёстко фильтровать RAG по `course_id` текущего курса. Если выключено, разрешены общие материалы из других курсов.

### 3. Limits & Token Budgets

- **Max contents** — сколько элементов курса передавать в LLM.
- **Max deadlines** — сколько ближайших дедлайнов передавать в LLM.
- **Organizational / Study beginner / Mixed / Default** — максимальная длина ответа LLM в токенах для разных сценариев.

### 4. Fallbacks & Course Starters

- **No LMS data** — ответ, когда в LMS нет запрошенных данных.
- **No RAG context** — ответ, когда в Базе знаний ничего не найдено.
- **Out of scope** — шаблон отказа, когда студент спрашивает про недоступный курс. Используйте `{course}` для подстановки названия.
- **Non-course starters** — слова, с которых начинаются обычные вопросы, но которые не являются названием курса. Помогают избежать ложного срабатывания «курс не найден».

## Как сохранить

Нажмите **Сохранить** в правом верхнем углу. После сохранения кэш чата автоматически сбрасывается.

## Подсказки

Наведите курсор на название параметра — появится всплывающая подсказка.
